Website SIERRA DARIEN merupakan project toko fashion online yang dirancang untuk menampilkan produk fashion wanita modern dengan tampilan yang elegan, interaktif, dan responsif.
Website ini terdiri dari 3 menu utama, yaitu Home (index.html) untuk menampilkan gambar promo/produk bestseller/produk baru, Product (index.html) untuk menampilkan beberapa products yang tersedia, serta Contact (contact.html) untuk menampilkan informasi kontak dan form untuk menghubungi toko.

Fungsi interaktif seperti tombol kembali ke atas, validasi form kontak, dan penutupan otomatis navbar di perangkat mobile diatur menggunakan file script.js, sedangkan tampilan visualnya didesain menggunakan styles.css dengan kombinasi warna hangat dan layout modern.
Website ini dibuat dengan HTML, CSS, Bootstrap, dan JavaScript, sehingga mampu menampilkan tampilan profesional yang mudah diakses di berbagai ukuran layar.
